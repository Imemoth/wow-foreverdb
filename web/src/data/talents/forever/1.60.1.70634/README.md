# WoW: Forever talent data - build 1.60.1.70634

- `<class>.json`, `manifest.json`: generated by `web/scripts/import-talent-catalog.mjs` from the Everloot talent catalog at the
  pinned commit (sha256 of every source and output file in `manifest.json`). `build.layoutCompatibleWith` records that the layout
  is identical to build 1.60.1.70630 (proven by the importer), so share links made for 70630 still decode. Do not edit by hand.
- `text.json`, `coverage.json`, `COVERAGE.md`: generated by `web/scripts/import-talent-text.mjs`. Client description templates
  proven against the build's text hashes, with per-rank values and explicit "?" gaps; `COVERAGE.md` lists every talent with its
  exact status and reason. Do not edit by hand.
- `icons.json`, `icons-inventory.json`: generated by `web/scripts/import-talent-icons.mjs`. FileDataIDs (spell id -> id) and the
  sha256/size of each image. **The images are Blizzard-owned and are not in this repository.**

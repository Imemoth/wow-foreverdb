## Architectural finding

`addon/ForeverDB/MapTracker.lua` captures one `C_Map.GetMapArtID(mapId)` and `C_Map.GetMapArtLayers(mapId)` / `C_Map.GetMapArtLayerTextures(mapId, index)` per UI map. It does not save exploration overlay state. `WowClientMapAssetProvider.LoadAsync` picks the largest usable art layer and resolves its FileDataIDs locally first, on the **same active build** Blizzard CDN second, then legacy `Interface\\WorldMap\\...` classic named textures. The renderer stitches that layer directly; it does **not** explicitly draw exploration masks. Consequently, do **not** assume an alternative MapArtID exists or that changing MapArtID alone reveals unexplored zones.

The separate WoW API `C_MapExplorationInfo.GetExploredMapTextures(uiMapID)` returns explored-region overlay FileDataIDs and offsets; this is a **different artwork pipeline** from `C_Map.GetMapArtLayerTextures`. It is a candidate diagnostic, **not** automatically a full-map replacement. Explore whether the existing base layer is already fully revealed and whether any fog is instead supplied by the exploration UI or baked into the actual client art. References:
- https://warcraft.wiki.gg/wiki/API:C_Map.GetMapArtLayerTextures
- https://warcraft.wiki.gg/wiki/API:C_MapExplorationInfo.GetExploredMapTextures

## Cache/fallback invariants and discovered risk

- The resolution entry key includes metadata, layer, resolver version and Wow build fingerprint; failures are memoized and concurrent work is deduplicated.
- The **PNG filename** currently uses only `mapId/artId/layerIndex` (`GetCachePath`) and `LoadAsync` checks existence before checking the keyed resolution entry. A future alternate-art strategy must **first** separate its cache namespace by variant + build fingerprint + texture-set identity (or safely invalidate/migrate old PNGs), otherwise an existing default bitmap can shadow the preferred variant or an older build.
- Preserve local-first CASC, exact-active-build CDN, legacy named-texture fallback and grid fallback on unresolved assets. Make negative caching per variant so one bad alternate does not suppress the original.
- Do not modify normalized coordinates or markers/clusters/heatmap/zone-navigation code as part of an art-only preference. Keep texture dimensions/aspect ratio compatible and status/diagnostics variant-aware.

## Proposed targeted regression matrix (not yet executed)

## Settings UX

Settings are staged in the UI and are persisted/applied only after pressing
`Save settings`. A successful save displays an explicit `Settings saved.`
confirmation in the Settings tab.


## Manual sync snapshot semantics

`Sync now` uploads the latest ForeverDB SavedVariables snapshot already written
to disk. It cannot force WoW to flush in-memory observations. Fresh loot collected
since the last SavedVariables write becomes visible to the Companion after WoW
writes the file, normally on `/reload`, logout or client exit. The STATUS UI now
states this explicitly so a successful manual upload is not mistaken for an
in-process WoW memory flush.

# ForeverDB 0.5 / Addon 0.3 acceptance test

## Addon

1. Run update-addon.cmd.
2. Start WoW Forever or /reload.
3. Confirm chat reports ForeverDB 0.3.0-alpha schema 8.
4. Run /fdb status.

### Gathering location tests

- Mine one ore node, then /fdb last.
- Gather one herb node, then /fdb last.
- Skin one creature and verify the exact creature level is retained.
- Open one chest/gameobject and verify a location is present after sync.

### Fishing pool test

1. Mouse over a named fishing pool so its tooltip appears.
2. Cast Fishing into the pool.
3. Loot the catch.
4. Run /fdb last.

Expected kind: fishing_pool. The recorded coordinate is a best-effort projected
pool position, not an exact server-side GameObject position.

### Disenchant test

1. Cast Disenchant.
2. Apply the spell cursor to a bag item.
3. Loot the enchanting materials.
4. Run /fdb last.

Expected kind: disenchant, source type: item, source ID: the disenchanted item ID.

## Companion

1. Build and run ForeverDB Companion 0.5.0-alpha.
2. Sync after WoW has written SavedVariables.
3. Verify item search results no longer show the Item # prefix.
4. Verify Back, Forward and breadcrumb navigation.
5. Verify mining/herbalism/pool results expose Location/Coords when observed.
6. Verify a Locations tab appears for observed gathering sources.

## Client map metadata

After at least one schema-8 location observation, the addon exports WoW client
map art metadata (map art ID, layers and FileDataIDs). The Companion stores this
under %LOCALAPPDATA%\ForeverDB\maps. The current preview remains the normalized
grid until the CASC + BLP extraction provider is connected.

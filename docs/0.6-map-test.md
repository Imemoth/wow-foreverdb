# ForeverDB 0.6 map / cluster / heatmap acceptance test

## Versions

- Addon: 0.3.1-alpha, schema 8
- Companion: 0.6.0-alpha

## Addon refresh

1. Run update-addon.cmd.
2. /reload in WoW.
3. Confirm: ForeverDB loaded 0.3.1-alpha schema 8.
4. Generate at least one new location observation (mining or fishing pool is enough).
5. /reload again so map metadata and the latest observation are written.

## Companion map asset

1. Build and run Companion 0.6.0-alpha.
2. Sync once.
3. Search for a location-backed item/source, e.g. Copper Vein, Copper Ore,
   Sagefish School or Raw Sagefish.
4. Open Locations.

Expected when local map extraction succeeds:

- Asset status starts with: WoW client map
- The coordinate grid is replaced by actual WoW map art.
- A PNG cache is created under %LOCALAPPDATA%\ForeverDB\maps\<mapId>.

Expected fallback if extraction fails:

- The grid remains visible.
- AssetStatusText shows the CASC/BLP reason.
- Markers, clusters and heatmap still work.

## Map interaction

- Mouse wheel zooms from 20% to 500%.
- Left-drag pans when the map is larger than the viewport.
- Fit returns to full-map view.

## Rendering modes

### Markers

- One marker per stored 0.5%-grid location row.
- Marker tooltip includes area, coordinates, loot kind and observation count.
- Mining, herbalism and fishing pools use distinct marker colors.

### Clusters

- Nearby points are grouped into weighted cells.
- Cluster center is weighted by observation count.
- The cluster badge shows point count when multiple points are grouped.

### Heatmap

- Heat intensity is weighted by observation count.
- Hotter locations visually outweigh one-off observations.
- A small center point remains hoverable for diagnostics.

## Current test data

The existing Copper Vein and Sagefish School observations are sufficient to
validate rendering. Herb and disenchant tests can wait until matching
characters are available.

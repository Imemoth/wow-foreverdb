# Guildbook Local-Only V1

The Companion stores Guildbook snapshots only at `%LOCALAPPDATA%\ForeverDB\guildbook\`, in an account/install namespace. Snapshot envelopes are protected with Windows DPAPI `CurrentUser` and committed atomically with a recoverable previous generation.

The WoW addon's SavedVariables file remains a separate local source and is not DPAPI-protected. It can contain the raw Guildbook export, so filesystem access to the WoW profile must be treated as access to that source. The Companion never includes those fields in the public observation payload and does not call a Guildbook RPC.

Account sign-out clears the in-memory view but preserves encrypted files. A different account uses a different namespace and cannot load the previous account's snapshot; an old capture is rejected after an account switch.
